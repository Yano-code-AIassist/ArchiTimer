# ArchiTimer

建築学科の学生や設計者向けの、長時間作業に強いWindowsタイマーです。

## フォルダー構成

| 場所 | 内容 |
|---|---|
| `ArchiTimer/` | アプリ本体（画面、タイマー処理、データ保存、通知） |
| `ArchiTimer.SmokeTests/` | 基本動作を確認するテスト |
| `tools/IconBuilder/` | アプリアイコン生成ツール |
| `dist/` | 配布用の実行ファイルとZIP |
| `distribution/` | 配布物に同梱する説明書 |
| `ArchiTimer.slnx` | Visual Studioで開くソリューション |

開発時に触る主な場所は `ArchiTimer/` です。`dist/` は生成済みの配布物なので、通常の開発では編集しません。

## 主な機能

- 99時間を超える通常タイマー
- 複数タイマーの同時実行、一時停止、再開、10分延長
- 25分集中／5分休憩を自動で切り替えるポモドーロ
- 0秒から作業時間を積み上げ、完了時に履歴へ残せるストップウォッチ
- 画面右下に置けるコンパクト表示と常に手前へ表示
- 作業プリセットと完了履歴のJSON保存
- 終了音とWindows通知
- UTCの終了日時を基準にし、スリープ復帰後も残り時間を補正

## 使い方

### 1. タイマーを始める

1. 「タイマー」タブで作業名を入力します。
2. 用途に合わせてモードを選びます。
3. 通常タイマーの場合だけ、時間と分を入力します。
4. 「タイマーを開始」を押します。

| モード | 用途 |
|---|---|
| 通常 | 設定時間から0秒までカウントダウン |
| ポモドーロ | 25分の集中と5分の休憩を自動で切り替え |
| ストップウォッチ | 0秒から作業時間を計測 |

複数のタイマーを同時に動かせます。進行中の作業では「一時停止／再開」「+10分」「削除」を使えます。ストップウォッチを記録するときは「作業完了」を押してください。

### 2. よく使う設定を保存する

作業名、モード、時間を入力して「プリセットとして保存」を押します。次回から「プリセット」タブの「開始」だけで同じ設定を使えます。

### 3. 完了した作業を確認する

「履歴」タブで完了日時、作業名、種類、作業時間を確認できます。不要になった履歴は「履歴を消去」でまとめて削除できます。

### 4. 小さく表示する

「コンパクト表示」を押すと、作業名と残り時間だけを小さく表示できます。「戻す」で通常画面に戻ります。ほかの画面の上に表示したい場合は「常に手前」をオンにします。

タイマー、プリセット、履歴は自動保存され、次回起動時にも引き継がれます。

## 開発環境

- C# / WPF / .NET 10
- Visual Studio 2026 Community、または .NET 10 SDKを認識できるVisual Studio

`ArchiTimer.slnx` をVisual Studioで開き、`ArchiTimer` をスタートアッププロジェクトにして実行します。

データは `%LOCALAPPDATA%\ArchiTimer\data.json` に保存されます。

## 別のパソコンへ配布する

Visual Studioの発行画面で `Windows-x64` プロファイルを選ぶか、次のコマンドを実行します。

```powershell
dotnet publish ArchiTimer\ArchiTimer.csproj -p:PublishProfile=Windows-x64
```

`ArchiTimer\bin\Publish\win-x64\ArchiTimer.exe` が生成されます。自己完結型のため、配布先に.NETを別途インストールする必要はありません。64bit版Windows 10/11向けです。
